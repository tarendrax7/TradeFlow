# TradeFlow

A full-stack MERN trading platform inspired by Zerodha. The project includes secure JWT authentication, a trading dashboard, holdings, positions, and buy order functionality.

---

## 🚀 Features

- User Signup & Login
- JWT Authentication
- Password Hashing using bcrypt
- Protected APIs
- Trading Dashboard
- Holdings Management
- Positions Management
- Buy Order API
- Responsive UI
- MongoDB Database Integration

---

## 🛠 Tech Stack

### Frontend
- React.js
- Bootstrap
- Axios

### Backend
- Node.js
- Express.js
- JWT Authentication
- bcrypt

### Database
- MongoDB

## ⚙️ Installation

### Clone the Repository

```bash
git clone https://github.com/tarendrax7/TradeFlow.git
```

### Go to Project Folder

```bash
cd TradeFlow
```

### Install Dependencies

#### Backend

```bash
cd backend
npm install
```

#### Frontend

```bash
cd frontend
npm install
```

#### Dashboard

```bash
cd dashboard
npm install
```

---

## ▶️ Run the Project

### Backend

```bash
cd backend
npm start
```

### Frontend

```bash
cd frontend
npm start
```

### Dashboard

```bash
cd dashboard
npm start
```

---

## 🔐 Environment Variables

Create a `.env` file inside the `backend` folder.

Example:

```env
PORT=5000
MONGO_URI=your_mongodb_connection_string
JWT_SECRET=your_secret_key
```
